Cara Setting Google Spreadsheet dan Mengambil Sheet ID

Panduan praktis membuat, mengatur akses, dan mengambil Sheet ID untuk kebutuhan automation.

Saat membangun automation dengan AI Agent, n8n, Google Apps Script, atau integrasi API lainnya, Anda hampir selalu membutuhkan satu informasi penting: Sheet ID. ID inilah yang dipakai sistem untuk mengenali spreadsheet mana yang harus dibaca atau ditulis. Artikel ini membahas cara membuat Google Spreadsheet, mengatur aksesnya, dan mengambil Sheet ID dengan benar.

1. Kenapa Sheet ID Penting?

Setiap Google Spreadsheet memiliki identitas unik berupa deretan karakter acak. Identitas ini dipakai oleh Google Sheets API, Apps Script, maupun tools automation seperti n8n untuk mengakses file yang tepat, tanpa harus mencari berdasarkan nama file yang bisa saja duplikat.

2. Membuat Google Spreadsheet Baru

Buka Google Drive, lalu pilih New → Google Sheets. Anda juga bisa langsung mengakses sheets.new di browser untuk membuat spreadsheet kosong secara instan.

Beri nama file yang jelas, misalnya sesuai fungsinya seperti "Database Leads" atau "Log Automation", agar mudah dikenali saat dikelola dalam jumlah banyak.

3. Struktur URL Spreadsheet

Setiap kali membuka spreadsheet, perhatikan URL pada address bar browser. Polanya selalu sama:

https://docs.google.com/spreadsheets/d/SHEET_ID/edit#gid=GID

Ada dua bagian penting di sini:

  • SHEET_ID — identitas unik untuk keseluruhan file spreadsheet.
  • GID — identitas untuk tab/sheet tertentu di dalam file tersebut.

Contoh URL

https://docs.google.com/spreadsheets/d/1AbCDeFGhijKLmnoPQRstuVWXyz1234567890abcd/edit#gid=987654321

Pada contoh di atas, bagian antara /d/ dan /edit adalah Sheet ID, sedangkan angka setelah gid= adalah GID tab tersebut.

4. Cara Mengambil Sheet ID

  1. Buka spreadsheet yang ingin diambil ID-nya.
  2. Lihat URL di address bar.
  3. Salin teks yang berada di antara /d/ dan /edit.

Teks tersebut biasanya terdiri dari huruf, angka, tanda hubung, dan garis bawah, dengan panjang sekitar 44 karakter.

5. Cara Mengambil GID (ID Tab/Sheet)

Jika spreadsheet memiliki beberapa tab (misalnya "Sheet1", "Sheet2", "Rekap"), setiap tab punya GID sendiri.

  1. Klik tab sheet yang dituju di bagian bawah spreadsheet.
  2. Perhatikan URL, angka setelah gid= akan berubah sesuai tab yang aktif.
  3. Salin angka tersebut sebagai GID.

GID 0 biasanya menunjuk ke tab pertama yang dibuat secara default.

6. Setting Akses Sharing

Agar spreadsheet bisa diakses oleh automation atau orang lain, atur permission melalui tombol Share di kanan atas.

  • Restricted — hanya orang yang diundang secara eksplisit yang bisa mengakses.
  • Anyone with the link (Viewer) — siapa saja dengan link bisa melihat, cocok untuk data publik non-sensitif.
  • Anyone with the link (Editor) — siapa saja dengan link bisa mengubah, sebaiknya dihindari untuk data penting.

Catatan Keamanan

Untuk automation yang menyimpan data sensitif seperti data pelanggan atau kredensial, gunakan akses Restricted dan tambahkan email Service Account secara spesifik, bukan opsi "Anyone with the link".

7. Menghubungkan ke Google Service Account

Jika Sheet ID akan dipakai lewat Google Sheets API (misalnya dari n8n, Python, atau Apps Script eksternal), spreadsheet perlu dibagikan ke email Service Account.

  1. Buat project di Google Cloud Console, aktifkan Google Sheets API.
  2. Buat Service Account, lalu unduh file JSON credential-nya.
  3. Salin alamat email Service Account, formatnya mirip nama-project@id-project.iam.gserviceaccount.com.
  4. Buka Share pada spreadsheet, tempel email tersebut, lalu beri akses Editor jika perlu menulis data.

8. Menggunakan Sheet ID di n8n

Pada node Google Sheets di n8n, Anda tinggal menempelkan Sheet ID pada kolom Document ID, dan GID pada kolom Sheet Name/Sheet ID sesuai versi node yang dipakai.

Document ID: 1AbCDeFGhijKLmnoPQRstuVWXyz1234567890abcd
Sheet: gid=987654321

Beberapa versi node n8n juga menerima URL spreadsheet secara langsung, sehingga Anda cukup paste seluruh link tanpa memisahkan ID dan GID secara manual.

9. Kesalahan Umum

  • Menyalin seluruh URL sebagai Sheet ID, padahal seharusnya hanya bagian di antara /d/ dan /edit.
  • Lupa membagikan spreadsheet ke email Service Account, sehingga API mengembalikan error permission.
  • Salah menempelkan GID tab lama setelah tab dihapus atau diganti urutannya.
  • Menggunakan akses Editor publik untuk data yang seharusnya bersifat privat.

FAQ

Apakah Sheet ID bisa berubah?

Tidak. Sheet ID bersifat permanen selama file tidak dihapus, meskipun nama file atau isi datanya diubah.

Apakah satu spreadsheet bisa punya banyak GID?

Ya. Setiap tab/sheet di dalam satu file spreadsheet memiliki GID yang berbeda-beda.

Apakah Sheet ID sama dengan Folder ID di Google Drive?

Berbeda. Folder ID dipakai untuk mengidentifikasi folder di Google Drive, sedangkan Sheet ID khusus untuk file Google Spreadsheet.

Apakah aman membagikan Sheet ID?

Sheet ID saja tidak cukup untuk mengakses file jika permission sharing diatur dengan benar, namun tetap sebaiknya tidak dipublikasikan sembarangan bersamaan dengan akses Editor publik.
