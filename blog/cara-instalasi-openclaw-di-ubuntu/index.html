Cara Instalasi OpenClaw di Ubuntu

1. Apa Itu OpenClaw?

OpenClaw adalah gateway AI assistant yang bisa berjalan di server pribadi. Dengan OpenClaw, kita bisa menghubungkan model AI, channel chat seperti Telegram atau Discord, workflow automation, tools server, dan memory workspace dalam satu sistem.

Jika dipasang di Ubuntu server, OpenClaw bisa aktif terus sebagai background service sehingga AI assistant tetap bisa menerima pesan dan menjalankan tugas walaupun terminal SSH sudah ditutup.

2. Kapan Cocok Dipasang di Ubuntu?

Instalasi di Ubuntu cocok untuk Anda yang ingin menjalankan assistant pribadi secara mandiri di VPS, mini PC, home server, atau server kantor.

  • Ingin AI assistant selalu online.
  • Ingin menghubungkan Telegram, Discord, WhatsApp, atau channel lain.
  • Ingin menyimpan workspace dan memory di server sendiri.
  • Ingin menjalankan automation dengan akses ke file, Docker, web server, atau aplikasi lokal.

3. Persiapan Server

Contoh di artikel ini memakai Ubuntu 24.04 LTS. Untuk server kecil, RAM 1 GB masih bisa dipakai, tetapi lebih nyaman jika memakai 2 GB RAM atau menambahkan swap.

sudo apt update
sudo apt upgrade -y
sudo apt install -y curl ca-certificates gnupg

Disarankan menjalankan OpenClaw sebagai user non-root agar file konfigurasi tersimpan rapi di home user tersebut.

sudo adduser openclaw
sudo usermod -aG sudo openclaw
sudo loginctl enable-linger openclaw
su - openclaw

4. Install Node.js

OpenClaw membutuhkan Node.js modern. Node.js 24 direkomendasikan, sedangkan Node.js 22.19 ke atas juga masih didukung.

curl -fsSL https://deb.nodesource.com/setup_24.x | sudo -E bash -
sudo apt install -y nodejs
node --version
npm --version

5. Install OpenClaw

Setelah Node.js siap, jalankan installer OpenClaw.

curl -fsSL https://openclaw.ai/install.sh | bash

Pastikan perintah openclaw sudah tersedia.

openclaw --version

6. Menjalankan Onboarding

Onboarding adalah proses awal untuk mengatur model AI, auth provider, gateway, channel, workspace, dan daemon service.

openclaw onboard --install-daemon

Ikuti wizard yang muncul. Biasanya Anda akan memilih provider model seperti OpenAI, Anthropic, Google, atau provider custom, lalu menyiapkan channel chat sesuai kebutuhan.

Catatan Keamanan

Simpan API key dan token channel dengan hati-hati. Jika server dipakai publik, jangan menaruh token di file yang bisa diakses dari web root seperti /var/www/html.

7. Menjalankan Gateway sebagai Service

Jika onboarding memakai opsi --install-daemon, OpenClaw akan memasang systemd user service. Service ini membuat gateway tetap berjalan setelah logout dari SSH.

systemctl --user status openclaw-gateway.service

Untuk melihat log secara realtime:

journalctl --user -u openclaw-gateway.service -f

Jika ingin restart gateway:

openclaw gateway restart

8. Verifikasi Instalasi

Setelah instalasi selesai, cek status OpenClaw dengan beberapa perintah berikut.

openclaw status
openclaw gateway status
openclaw doctor --non-interactive

Jika gateway berjalan di port default, health check lokal bisa dicek dengan:

curl -fsS http://127.0.0.1:18789/healthz
curl -fsS http://127.0.0.1:18789/readyz

9. Menghubungkan Channel

OpenClaw bisa dipakai langsung dari Control UI, tetapi biasanya lebih menarik jika dihubungkan ke channel chat seperti Telegram atau Discord.

Untuk Telegram, buat bot melalui BotFather, ambil bot token, lalu hubungkan ke OpenClaw melalui wizard atau konfigurasi channel.

openclaw channels list
openclaw channels add --channel telegram --token "<BOT_TOKEN>"

Sesuaikan command dengan versi CLI yang digunakan. Jika ragu, jalankan:

openclaw channels --help

10. Tambahkan Swap untuk Server Kecil

Jika memakai VPS 1 GB RAM, tambahkan swap agar proses instalasi dan gateway lebih stabil.

sudo fallocate -l 2G /swapfile
sudo chmod 600 /swapfile
sudo mkswap /swapfile
sudo swapon /swapfile
echo '/swapfile none swap sw 0 0' | sudo tee -a /etc/fstab

11. Troubleshooting

Gateway tidak menyala

openclaw doctor --non-interactive
journalctl --user -u openclaw-gateway.service -n 80

Port 18789 sudah dipakai

sudo lsof -i :18789

Matikan proses yang bentrok atau ubah port gateway lewat konfigurasi OpenClaw.

Command openclaw tidak ditemukan

Pastikan terminal sudah memuat PATH dari installer. Logout-login SSH, atau cek lokasi binary:

which openclaw
npm bin -g

Server kehabisan memori

Tambahkan swap, gunakan model API-based, dan hindari menjalankan local LLM besar di VPS kecil.

12. Best Practice Setelah Instalasi

  • Gunakan user non-root khusus untuk OpenClaw.
  • Aktifkan firewall dan batasi port publik.
  • Simpan backup folder ~/.openclaw/.
  • Gunakan SSH tunnel, VPN, atau Tailscale untuk akses Control UI.
  • Jangan commit API key atau bot token ke repository.

FAQ

Apakah OpenClaw bisa dipasang di VPS murah?

Bisa. VPS 1 GB RAM dapat dipakai untuk gateway ringan, tetapi sebaiknya tambahkan swap atau gunakan VPS 2 GB RAM agar lebih nyaman.

Apakah harus memakai Docker?

Tidak. Instalasi langsung di Ubuntu cukup untuk banyak kebutuhan. Docker cocok jika ingin isolasi environment.

Apakah OpenClaw harus memakai OpenAI?

Tidak. OpenClaw dapat dikonfigurasi dengan beberapa provider model, termasuk provider API lain atau custom provider.

Di mana data OpenClaw disimpan?

Umumnya di folder ~/.openclaw/ milik user yang menjalankan OpenClaw. Workspace agent berada di ~/.openclaw/workspace/.
